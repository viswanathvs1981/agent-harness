# Drop bots and skills here.

- A **bot** is a folder `.agents/bots/<name>/BOT.md`
- A **skill** is a folder `.agents/skills/<name>/SKILL.md`

Copy a folder in to add it. Do not put secrets here. Local run state belongs in `.harness/` (not committed).

Default: bots do not update, delete, or commit files unless the message asks. Work stays inside this project.
