# Shaping the build

Implementation is getting cheaper. The scarce skill is choosing the problem, the workflow, the success bar, and the evidence.

Write a spec a coding agent can execute: outcome, constraints, evals, non-goals. Know when a messy spike is the right next step and when to slow down (money, safety, data you cannot un-eat).
