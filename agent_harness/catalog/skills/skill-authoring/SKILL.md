# Skill authoring

Follow the Agent Skills open standard: folder + `SKILL.md` with `name` and `description`. Description must say **what** and **when**. Keep the body under ~500 lines; put details in `references/`. Name matches directory, lowercase-hyphen. Skills teach procedures; they are not agents.
